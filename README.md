## Проекты

### [Jumping Fitness](https://github.com/FalkM49/jumping-fitness) — в работе у студии
Приложение для студии групповых тренировок: запись на занятия, абонементы, расписание тренера,
push-уведомления. Android + веб-версия для iPhone.

- Вся бизнес-логика — в серверных транзакциях, защищённых правилами Firestore
- Перенос бэкенда с Firebase Cloud Functions на Yandex Cloud без переписывания логики
- PWA для iPhone с веб-push вместо App Store
- 250+ автотестов: приложение, сервер, правила безопасности

`Flutter` `Firebase` `TypeScript` `Yandex Cloud` `PWA`
